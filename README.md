# MediVault Admin Panel

Comprehensive administrative portal and platform management console for **MediVault** — the Personal Health Record, Family Health Locker & Healthcare Discovery Platform.

## Features
- **Executive Analytics**: Real-time health locker KPIs, storage metrics, and OCR processing health.
- **User & Family Management**: 360° user profile inspection, family dependent network graph, and DPDP/GDPR data erasure workflows.
- **Health Records & OCR Queue**: Central document locker, OCR text extraction triage, and strict Break-Glass privacy controls.
- **Healthcare Discovery**: Provider directory (hospitals, clinics, labs, pharmacies), verification badging, and moderation queues.
- **Communications & Alerts**: Public health advisories composer and partner promotional offers with strict separation rules.
- **Support & Monetization**: Multi-tier customer support workbench, subscription plan management (Free vs ₹499/member/month), and GST invoicing.
- **Security & Compliance**: Immutable administrative audit trails, emergency QR scan access telemetry, and role-based access control (RBAC).

## Getting Started

### Prerequisites
- Node.js 18+ (verified on Node.js 22+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
